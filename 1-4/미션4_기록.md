### `영화_기능추가.html` 완성 기준별 확인 ('처음으로'를 먼저 누르고 처음부터)

**원래 기준 7개**

| 완성 기준 | 해 본 행동 | 결과 |
|---|---|---|
| 영화가 한 칸에만 있고, 옮긴 칸에 남는다 | 영화 8개를 누르기로 S칸, 끌어 놓기로 A칸에 옮기기 (2번 반복). 기생충을 B칸, 인터스텔라를 C칸으로 옮겼다가 미분류로 되돌리기 | ✅ 8개 모두 두 방법 다 옮겨졌고 2번 다 같았다. 카드는 한 칸에만 있었다 |
| 제목을 입력하면 새 영화 카드가 생긴다 | `듄` 입력 후 추가 | ✅ 미분류에 듄 카드가 생겼다 |
| 다시 열어도 영화와 등급이 남는다 | 기생충을 S칸에 옮기고 듄을 추가한 뒤 새로고침 | ✅ 기생충은 S칸, 듄은 미분류에 그대로 있었다 |
| 화면 폭이 좁아져도 오른쪽이 잘리지 않는다 | 창 너비를 휴대폰 정도로 줄이고 TMDB 설정도 열어 보기 | ✅ 오른쪽이 잘리지 않았다 |
| '처음으로'를 누르면 8개가 모두 미분류로 돌아간다 | 옮기고 듄을 추가한 뒤 '처음으로' | ✅ 듄은 사라지고 8개 모두 미분류로 돌아왔다 |
| HTML 한 장으로 열린다 | 파일을 바로 열기 | ✅ 다른 파일이나 로그인 없이 열렸다 |
| 빈 제목은 추가하지 않는다 | 빈칸, 띄어쓰기만 넣고 추가 | ✅ "영화 제목을 입력해 주세요." 안내가 뜨고 카드가 생기지 않았다 |

**[더할 기능] 기준 9개** (실제 TMDB 인증값으로 확인)

| 완성 기준 | 해 본 행동 | 결과 |
|---|---|---|
| 검색하면 포스터·제목·개봉 연도와 함께 최대 5개 보인다 | '기생충', '스파이더맨' 검색 | ✅ '기생충'은 4개, '스파이더맨'은 5개까지만 보였고 모두 포스터·제목·연도가 있었다 |
| 결과에서 '추가'를 누르면 카드가 생기고 옮길 수 있다 | '패러사이트' 추가 후 누르기로 S칸, 끌어 놓기로 B칸 | ✅ 미분류에 카드가 생겼고 두 방법 다 옮겨졌다 |
| 이미 있는 제목은 다시 추가하지 않는다 | 결과에서 '기생충' 추가, '패러사이트' 한 번 더 추가 | ✅ 둘 다 "이미 있는 영화 제목이에요" 안내가 뜨고 카드가 늘지 않았다 |
| 검색어가 비어 있으면 검색하지 않는다 | 빈칸, 띄어쓰기만 넣고 검색 | ✅ "검색어를 입력해 주세요." 안내가 떴다 |
| 설정에서 입력·교체·삭제, 연결 성공·실패 안내 | 틀린 값 저장 → 맞는 값 저장 → 다시 열어 교체 → 삭제. 보기·숨기기도 눌러 보기 | ✅ 틀린 값은 실패 안내 후 저장되지 않았고, 맞는 값은 성공 안내 후 저장됐다. 교체·삭제·보기·숨기기 모두 됐다 |
| 인증값은 이 브라우저에만, 파일에 없음, '처음으로'에도 남음 | 저장 후 '처음으로' 누르고 다시 검색. HTML 파일을 메모장으로 열어 보기 | ✅ '처음으로' 뒤에도 검색이 됐고, 파일 안에는 인증값이 없었다 |
| 인증값이 없거나 틀리면 안내와 설정 버튼, 직접 추가는 됨 | 인증값 없이 검색, 틀린 인증값으로 처음 검색하는 단어 검색, 그 상태로 `듄` 직접 추가 | ✅ 안내와 'TMDB 설정' 버튼이 떴고 직접 추가는 그대로 됐다 |
| 검색해서 추가한 영화도 다시 열면 남고 '처음으로'에 사라진다 | '패러사이트'를 B칸에 두고 새로고침 → '처음으로' | ✅ 새로고침 뒤 B칸에 남았고 '처음으로'에 사라졌다 |
| 화면 아래에 TMDB 출처가 보인다 | 화면 맨 아래 보기 | ✅ TMDB 출처 문구가 보였다 |

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 새 기능이 보이는 것만 확인했는지, 원래 기능(옮기기·추가·저장·'처음으로')까지 처음부터 다시 해 봤는지 비교해 보고 싶다. 새 기능이 잘 되면 원래 기능 확인을 건너뛰기 쉽기 때문이다.
