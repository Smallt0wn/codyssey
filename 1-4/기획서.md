# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## [더할 기능] TMDB로 영화 검색해서 추가하기

### 화면과 동작

- 제목 입력칸 위에 TMDB 검색창과 ‘검색’ 버튼, ‘TMDB 설정’ 버튼을 둡니다.
- 검색어를 입력하고 ‘검색’을 누르면 TMDB 한국어 검색 결과를 최대 5개 보여 줍니다. 결과마다 포스터, 제목, 개봉 연도, ‘추가’ 버튼이 있습니다.
- 검색 결과에서 ‘추가’를 누르면 그 영화 제목으로 아직 안 정한 영화에 카드가 생깁니다. 카드는 다른 카드처럼 제목만 보여 줍니다.
- ‘TMDB 설정’에서 TMDB API 키(v3) 또는 읽기 액세스 토큰을 입력·교체·삭제합니다. 저장할 때 연결을 확인해 성공·실패를 알려 주고, 입력값은 가려서 보여 주며 보기·숨기기를 할 수 있습니다.
- 인증값은 이 브라우저에만 저장하고 HTML 파일과 영화 목록 저장에는 넣지 않습니다. ‘처음으로’를 눌러도 인증값은 지워지지 않습니다.
- 인증값이 없거나 틀리거나 인터넷 연결 문제로 검색이 안 되면 검색 영역에 안내와 ‘TMDB 설정’ 버튼을 보여 줍니다. 이때도 제목 직접 추가는 그대로 쓸 수 있습니다.
- 화면 아래에 TMDB 출처를 표시합니다.

### 필요한 자료

- TMDB API (한국어 결과). 비상업적 무료 이용 조건에 따라 화면 아래에 출처를 표시합니다.

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.

### [더할 기능] 완성 기준

- 검색창에 영화 제목을 입력하고 ‘검색’을 누르면 TMDB에서 찾은 영화가 포스터, 제목, 개봉 연도와 함께 최대 5개 보입니다.
- 검색 결과에서 ‘추가’를 누르면 아직 안 정한 영화에 그 영화 카드가 생기고, 다른 카드처럼 누르거나 끌어서 옮길 수 있습니다.
- 이미 있는 제목의 영화는 검색 결과에서 다시 추가하지 않고 안내를 보여 줍니다.
- 검색어가 비어 있으면 검색하지 않고 안내를 보여 줍니다.
- ‘TMDB 설정’에서 API 키(v3) 또는 읽기 액세스 토큰을 입력·교체·삭제할 수 있고, 저장할 때 연결 성공·실패 안내가 보입니다.
- TMDB 인증값은 이 브라우저에만 저장되고 HTML 파일에는 적혀 있지 않으며, ‘처음으로’를 눌러도 지워지지 않습니다.
- TMDB 인증값이 없거나 틀리면 검색 영역에 안내와 ‘TMDB 설정’ 버튼이 보이고, 제목 직접 추가는 그대로 쓸 수 있습니다.
- 검색해서 추가한 영화도 다시 열었을 때 남고, ‘처음으로’를 누르면 사라집니다.
- 화면 아래에 TMDB 출처가 보입니다.
