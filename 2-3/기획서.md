# Mac VS Code 단축키 연습장

## 대상 사용자

- Mac으로 개발 공부를 시작한 나. VS Code에서 주석 달기, 줄 옮기기 같은 일을 할 때마다 메뉴를 찾아 마우스로 누릅니다. Mac 노트북(크롬 브라우저)에서만 씁니다.

## 사용 목적

- 자주 쓰는 VS Code 단축키를 직접 눌러 보며 손에 익힙니다. 타임어택으로 얼마나 빨리 떠올리는지 확인하고, 브라우저와 Mac 기본 단축키는 설명서처럼 찾아 봅니다.

## 화면 구성과 동작

- 맨 위에 ‘Mac VS Code 단축키 연습장’이 있고, 그 아래에 탭 다섯 개가 두 묶음으로 나뉘어 있습니다: ‘키를 눌러 연습하기’(‘연습 모드’, ‘타임어택’)와 ‘단축키 표 보기’(‘VS Code’, ‘브라우저’, ‘Mac 기본’). 처음 열면 ‘연습 모드’ 탭이 선택되어 있습니다.
- ‘연습 모드’와 ‘타임어택’ 탭 아래쪽에는 Mac 키보드 그림이 있습니다. ⌘ ⌥ ⌃ ⇧ 키와 방향키가 실제 Mac 배열대로 있습니다.
- 키를 누르는 동안 키보드 그림에서 그 키에 불이 들어오고, 떼면 꺼집니다. 여러 키를 함께 누르면 함께 켜집니다. 키보드 그림 위에는 지금 누른 조합이 ‘⌘ ⇧ P’처럼 글자로도 나옵니다.
- 키를 누르는 순서는 상관없습니다. P를 먼저 누르고 ⌘ ⇧를 이어 눌러도 함께 눌렸으면 ⌘ ⇧ P로 판정합니다.
- ‘연습 모드’와 ‘타임어택’ 탭에서는 누른 키가 브라우저로 넘어가지 않아 ⌘ R이나 ⌘ L을 눌러도 새로고침이나 주소창 이동이 되지 않습니다. 설명서 탭에서는 브라우저 단축키가 그대로 동작합니다.
- **연습 모드**
  - VS Code 단축키 15개가 무작위 순서로 한 문제씩 나옵니다. 몇 번째 문제인지(3 / 15)와 진행 막대가 보입니다.
  - 문제 카드에 기능 이름과 한 줄 설명이 나옵니다. (예: ‘명령 팔레트 열기 — VS Code의 모든 기능을 이름으로 찾아 실행합니다.’)
  - 맞는 조합을 누르면 카드가 초록색으로 바뀌고 ‘맞았어요! ⌘ ⇧ P’가 나온 뒤 다음 문제로 넘어갑니다.
  - 틀린 조합을 누르면 카드가 연한 붉은색으로 바뀌고 ‘지금 누른 키: ⌘ P. 다시 눌러 보세요.’가 나옵니다. ⌘ ⌥ ⌃ ⇧만 누르고 뗀 것은 틀린 것으로 세지 않습니다.
  - ‘정답 보기’를 누르면 키보드 그림에서 정답 키에 금색 테두리가 생깁니다. 정답을 본 문제는 첫 시도 정답으로 세지 않습니다.
  - ‘건너뛰기’를 누르면 다음 문제로 넘어갑니다. 건너뛴 문제는 첫 시도 정답으로 세지 않고 다시 연습할 목록에 들어갑니다. 버튼 아래에 ‘눌러도 키가 켜지지 않으면 다른 앱이 먼저 쓰는 키일 수 있어요. 건너뛰고 계속할 수 있습니다.’가 나옵니다.
  - 15문제를 다 풀면 ‘첫 시도 정답 12 / 15개 (80%)’, 틀린 횟수, 정답을 본 문제 수, 건너뛴 수, 다시 연습할 단축키 목록(기능 이름과 정답 키)이 나오고 ‘결과 이미지 저장’과 ‘다시 연습하기’ 버튼이 있습니다.
- **타임어택**
  - ‘시작’을 누르면 60초가 줄어들기 시작하고, 연습 단축키 15개 중에서 문제가 무작위로 하나씩 나옵니다. 같은 문제가 연달아 나오지는 않습니다. 남은 시간이 숫자와 막대로 보입니다.
  - 맞고 틀림은 연습 모드와 같은 방식으로 판정합니다. ⌘ ⌥ ⌃ ⇧만 누르고 뗀 것은 틀린 것으로 세지 않습니다.
  - 맞으면 맞힌 수가 1 늘고 바로 다음 문제가 나옵니다. 새 문제 아래에는 ‘맞았어요! 방금 문제의 답: ⌘ ⇧ P’처럼 직전 문제의 답임을 밝혀 보여 줍니다. 틀리면 틀린 수가 1 늘고 같은 문제가 그대로 있습니다. ‘건너뛰기’를 누르면 건너뛴 수가 1 늘고 다음 문제로 넘어갑니다.
  - 다른 탭으로 옮겨도 남은 시간은 멈추지 않고 계속 줄어듭니다.
  - 60초가 끝나면 ‘맞힘 9 · 틀림 3 · 건너뜀 1’이 나오고 ‘결과 이미지 저장’과 ‘다시 하기’ 버튼이 있습니다. 끝난 뒤에는 키를 눌러도 점수가 바뀌지 않습니다.
- **결과 이미지 저장**
  - ‘결과 이미지 저장’을 누르면 결과 카드가 PNG 그림 파일로 내려받아집니다. 파일 이름은 ‘단축키연습_연습모드_2026-11-06.png’, ‘단축키연습_타임어택_2026-11-06.png’처럼 모드와 날짜가 붙습니다. 저장하면 결과 화면에 저장했다는 안내와 파일 이름, 확인할 곳이 나옵니다.
  - 그림에는 모드, 날짜와 시각, 점수가 나옵니다. 연습 모드 그림에는 다시 연습할 단축키 목록도 들어갑니다.
- **설명서 탭 (VS Code · 브라우저 · Mac 기본)**
  - 탭마다 단축키 표가 있습니다. 표에는 ‘키 · 하는 일’이 나오고, 키는 ⌘ ⌥ ⌃ ⇧ 기호로 적습니다.
  - ‘VS Code’ 탭에는 연습 모드에 나오는 15개가 있습니다. ‘브라우저’ 탭과 ‘Mac 기본’ 탭은 읽기 전용입니다.
- 휴대폰이나 태블릿처럼 화면이 좁거나 키보드가 없는 기기에서 열면 ‘이 연습장은 Mac 컴퓨터의 키보드로 이용해 주세요.’ 안내만 보이고 탭과 연습 화면은 보이지 않습니다.

## 필요한 자료

- **연습 단축키: VS Code (Mac) 15개.** 브라우저 안에서 눌러도 탭이 닫히거나 창이 바뀌지 않는 단축키만 골랐습니다. 실제 Mac에서 입력되지 않은 ⌘ ⇧ K와 ⇧ ⌥ ↓는 뺐습니다.

  | 키 | 하는 일 |
  |---|---|
  | ⌘ P | 파일 이름으로 빠르게 열기 |
  | ⌘ ⇧ P | 명령 팔레트 열기 |
  | ⌘ B | 사이드바 보이기·숨기기 |
  | ⌘ / | 줄 주석 달기·없애기 |
  | ⌘ D | 같은 단어 하나 더 선택하기 |
  | ⌥ ↑ | 줄을 위로 옮기기 |
  | ⌥ ↓ | 줄을 아래로 옮기기 |
  | ⌃ G | 원하는 줄로 이동하기 |
  | ⌘ \ | 편집기 나누기 |
  | ⌘ Enter | 아래에 새 줄 넣기 |
  | ⌘ ⇧ Enter | 위에 새 줄 넣기 |
  | ⌥ ⌘ F | 찾아 바꾸기 |
  | ⌘ ⇧ F | 모든 파일에서 찾기 |
  | ⌃ ` | 터미널 열기·닫기 |
  | ⇧ ⌥ F | 문서 서식 맞추기 |

- **설명서: 브라우저 (크롬 기준).** 새 탭 ⌘ T, 탭 닫기 ⌘ W, 닫은 탭 다시 열기 ⌘ ⇧ T, 주소창 ⌘ L, 새로고침 ⌘ R, 강력 새로고침 ⌘ ⇧ R, 페이지에서 찾기 ⌘ F, 북마크 ⌘ D, 개발자 도구 ⌥ ⌘ I, 뒤로·앞으로 ⌘ [ · ⌘ ], 확대·축소·원래 크기 ⌘ + · ⌘ − · ⌘ 0, 시크릿 창 ⌘ ⇧ N
- **설명서: Mac 기본.** 복사·붙여넣기·잘라내기 ⌘ C · ⌘ V · ⌘ X, 실행 취소·다시 실행 ⌘ Z · ⌘ ⇧ Z, 전체 선택 ⌘ A, 저장 ⌘ S, 창 닫기 ⌘ W, 앱 종료 ⌘ Q, 앱 전환 ⌘ Tab, Spotlight 검색 ⌘ Space, 화면 캡처 ⌘ ⇧ 3 · ⌘ ⇧ 4 · ⌘ ⇧ 5, 강제 종료 ⌥ ⌘ Esc, 화면 잠금 ⌃ ⌘ Q
- 단축키의 출처 (뜻만 참고하고 설명 문장은 직접 씁니다)
  - VS Code: Mac 단축키 공식 PDF <https://code.visualstudio.com/shortcuts/keyboard-shortcuts-macos.pdf>
  - 브라우저: Chrome 고객센터 ‘Chrome 키보드 단축키’ <https://support.google.com/chrome/answer/157179>
  - Mac 기본: Apple 지원 ‘Mac 키보드 단축키’ <https://support.apple.com/ko-kr/102650>
- 키보드 그림은 사진 없이 화면에 직접 그립니다. 글꼴은 기기에 있는 기본 글꼴을 쓰고, 인터넷에서 글꼴·사진·라이브러리를 불러오지 않습니다.

## 완료 기준

- HTML 파일을 열면 탭 다섯 개와 ‘연습 모드’ 문제 카드(1 / 15), Mac 키보드 그림이 보입니다.
- ⌘ ⇧ P를 함께 누르면 키보드 그림에서 세 키가 함께 켜지고 위에 ‘⌘ ⇧ P’가 나옵니다. 키를 모두 떼면 불이 모두 꺼집니다. ⌘를 누른 채 P만 뗐다가 ⌘를 떼도 불이 남지 않습니다.
- 한글 입력 상태에서 눌러도 영문 입력 상태와 똑같이 판정됩니다.
- 연습 모드에서 15개를 모두 맞게 누르면 결과 화면에 ‘첫 시도 정답 15 / 15개 (100%)’가 나옵니다.
- 틀린 조합을 누르면 누른 키가 ‘지금 누른 키’에 나오고, 맞힐 때까지 다음 문제로 넘어가지 않습니다. 한 번 틀린 뒤 맞힌 문제와 ‘정답 보기’를 누른 문제는 첫 시도 정답에 세지 않습니다.
- 결과 화면과 결과 이미지에 ‘정답 본 문제 2개’처럼 정답을 본 문제 수가 나옵니다.
- ‘건너뛰기’를 누르면 다음 문제로 넘어가고, 건너뛴 문제는 결과의 건너뜀 수와 다시 연습할 목록에 나옵니다. 15개를 모두 건너뛰어도 결과 화면까지 갑니다.
- 같은 조합을 P → ⌘ → ⇧, ⌘ → P → ⇧, ⇧ → ⌘ → P처럼 다른 순서로 눌러도 맞다고 판정합니다. Z처럼 틀린 키는 그대로 틀림으로 셉니다.
- 15문제 안에 같은 문제가 두 번 나오지 않고, ‘다시 연습하기’를 누르면 1 / 15부터 다른 순서로 다시 나옵니다.
- 크롬에서 연습 단축키 15개를 모두 눌러도 인쇄 창이 열리거나 북마크가 추가되는 등 브라우저 동작이 일어나지 않습니다.
- 타임어택에서 ‘시작’을 누르면 남은 시간이 60부터 1초씩 줄고, 0이 되면 결과가 나옵니다. 끝난 뒤에는 키를 눌러도 맞힘·틀림 수가 바뀌지 않습니다.
- 타임어택 결과의 맞힘·틀림·건너뜀 수가 직접 세어 둔 수와 같고, 같은 문제가 연달아 나오지 않습니다.
- 결과 화면에서 ‘결과 이미지 저장’을 누르면 저장 안내가 나오고, 모드와 날짜가 붙은 PNG 파일이 내려받아지고, 그 파일을 열면 화면의 결과와 같은 점수(연습 모드는 다시 연습할 목록까지)가 보입니다.
- ‘VS Code’ 탭에 연습 단축키 15개가 모두 있고, ‘브라우저’·‘Mac 기본’ 탭은 읽기 전용입니다.
- 크롬 창 폭을 휴대폰 정도로 줄이면 컴퓨터 키보드로 이용해 달라는 안내만 보입니다. 다시 넓히면 연습 화면이 돌아옵니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다. 글꼴·사진·라이브러리를 인터넷에서 불러오지 않습니다.
- 연습 기록과 타임어택 점수는 페이지에 저장하지 않습니다. 새로고침하면 처음부터 시작합니다. 기록은 결과 이미지 파일로만 남깁니다.

## 필수 기능

- 상단 탭 다섯 개로 연습 모드, 타임어택, 설명서 세 개(VS Code · 브라우저 · Mac 기본) 오가기
- 누른 키를 Mac 키보드 그림과 글자로 실시간 표시
- 연습 모드: VS Code 단축키 15개를 무작위 순서로 풀고, 틀리면 다시 누르기·정답 보기·건너뛰기, 끝나면 첫 시도 정답 비율과 다시 연습할 목록
- 타임어택: 60초 동안 맞힘·틀림·건너뜀 세기, 끝나면 결과와 다시 하기
- 결과 이미지 저장: 연습 모드와 타임어택 결과를 날짜가 붙은 PNG 파일로 내려받기
- 휴대폰·태블릿에서는 컴퓨터로 이용해 달라는 안내만 보여 주기

## 추가 기능

- Windows 키보드 배열과 Windows용 단축키
- 다른 앱(Figma, 노션 등) 단축키 설명서 탭

## 한계 및 비목표

1. 연습 문제는 VS Code 단축키 15개만 나옵니다. ⌘ W, ⌘ Q, ⌘ Tab처럼 브라우저나 Mac이 먼저 실행하는 단축키는 설명서 탭에서 읽기만 할 수 있습니다. 연습 단축키라도 컴퓨터 환경에 따라 페이지까지 입력이 오지 않으면 맞힐 수 없고, ‘건너뛰기’로 넘어갑니다.
2. Mac 컴퓨터의 크롬을 기준으로 만듭니다. 휴대폰·태블릿에서는 연습할 수 없고, Windows 키보드 배열과 다른 브라우저의 판정은 확인하지 않습니다.
3. 연습 기록과 타임어택 점수는 페이지에 저장하지 않습니다. 남기고 싶으면 결과 이미지를 내려받아야 하고, 지난 기록을 페이지에서 다시 볼 수는 없습니다.

## 검증 방법

- ‘VS Code’ 탭과 연습 문제에 나온 단축키 15개를 VS Code 공식 Mac 단축키 PDF(<https://code.visualstudio.com/shortcuts/keyboard-shortcuts-macos.pdf>)와 하나씩 대조합니다. 키 조합이나 하는 일이 다르면 표시해 두고, 실제 VS Code에서 그 키를 눌러 같은 기능이 실행되는지 확인한 뒤 고칩니다.
