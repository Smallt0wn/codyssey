# 민수 님께 드리는 피드백

안녕하세요 민수님 몇가지 잘된 점, 고치면 좋을 점 순으로 피드백을 드리려고 해요!!

## 잘된 점

1. 직접 사용해 보니 S·A·B·C 등급의 색이 달라서 구분하기 쉬웠습니다.
2. 카드를 끌어 놓을 때 해당 칸의 배경색이 바뀌는 점도 어디에 놓이는지 알기 좋았습니다.
3. 영화를 옮길 때마다 전체 영화 수와 분류한 영화 수가 바로 바뀌는 것도 정리 상황을 확인하는 데 도움이 됐습니다.
4. `처음으로`를 누르면 직접 추가한 영화까지 없어지고 처음 영화 8개가 모두 미분류로 돌아오는 기능은 기획서대로 잘 작동했습니다.

## 고치면 좋을 점

1. **본 것:** 영화를 S등급으로 옮기고 새 영화를 추가한 뒤 페이지를 다시 열었더니 처음 상태로 돌아왔습니다.

   **기준:** 기획서의 “같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.”

    **제안:** 영화를 추가하거나 옮길 때마다 현재 목록과 등급을 브라우저 저장소에 저장하고, 페이지를 열 때 저장된 내용을 불러오면 좋겠습니다. `처음으로`를 눌렀을 때는 저장된 내용도 처음 목록으로 바뀌어야 합니다.
2. **본 것:** 창 너비를 휴대폰 정도로 줄였더니 페이지 오른쪽이 잘렸고, 옆으로 스크롤도 되지 않아 `처음으로` 버튼 같은 일부 내용을 볼 수 없었습니다.

   **기준:** 기획서의 “화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.”

    **제안:** 페이지의 고정 너비 대신 화면에 맞는 최대 너비를 사용하고, 좁은 화면에서는 등급 이름과 영화 카드 크기가 함께 줄어들도록 바꾸면 좋겠습니다.
3. **본 것:** 제목을 입력하지 않고 추가를 눌렀더니 글자 없는 카드가 생겼습니다. 띄어쓰기만 넣고 추가해도 똑같이 빈 카드가 생겼습니다.

   **기준:** 기획서에는 없지만 쓰다가 불편했던 점입니다. 영화를 제목으로 구분하고 정리하는 페이지인데 빈 카드는 어떤 영화인지 알 수 없습니다.

    **제안:** 앞뒤 공백을 지운 제목이 비어 있으면 카드를 만들지 말고 “영화 제목을 입력해 주세요”라는 안내를 보여 주면 좋겠습니다.
4. **본 것:** 이미 있는 `기생충`을 입력해도 같은 제목의 카드가 하나 더 생겼습니다.

   **기준:** 기획서에는 없지만 쓰다가 헷갈렸던 점입니다. 같은 제목의 카드가 두 장이면 어느 카드가 원래 카드인지 알기 어렵고, 한 영화를 두 등급에 나눠 놓게 될 수 있습니다.

    **제안:** 추가하기 전에 같은 제목이 있는지 확인하고, 이미 있다면 새 카드를 만들지 않고 안내를 보여 주면 좋겠습니다.  


    4번은 따로 받은 피드백에는 없었지만 직접 확인하면서 추가로 찾은 내용입니다!
