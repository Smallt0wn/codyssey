# 미션 3 기록

## 먼저 직접 확인한 결과

| 완성 기준 | 직접 해 본 방법 | 결과 |
|---|---|---|
| 영화가 한 칸에만 있고 옮긴 칸에 남는다 | 인터스텔라 카드를 선택해 S 등급을 누르고, 다시 미분류로 옮겨 봤다. | 카드는 한 곳에만 표시됐고 선택한 칸으로 잘 이동했다. |
| 제목을 입력하면 새 영화 카드가 생긴다 | `듄`을 입력하고 추가를 눌렀다. | 미분류 영역에 듄 카드가 생겼다. |
| 같은 파일을 다시 열어도 영화와 등급이 남는다 | 영화를 S 등급으로 옮기고 새 영화를 추가한 다음 페이지를 다시 열어 봤다. | 처음 영화 8개가 모두 미분류인 상태로 돌아왔다. 저장 기준을 만족하지 못했다. |
| 좁은 화면에서도 오른쪽이 잘리지 않는다 | 창 너비를 휴대폰 정도로 줄여 봤다. | 오른쪽 내용이 잘렸고 옆으로 스크롤도 안 됐다. |
| 처음으로를 누르면 처음 영화 8개가 미분류로 돌아간다 | 영화를 옮기고 듄을 추가한 뒤 처음으로를 눌렀다. | 추가한 듄은 사라지고 처음 영화 8개만 미분류로 돌아왔다. |
| 외부 파일이나 로그인 없이 HTML 한 장으로 열린다 | HTML 파일을 바로 열어 봤다. | 로그인이나 다른 파일 없이 화면이 열렸다. |

## 받은 의견 확인

| 받은 의견                                       | 직접 해 본 결과                                                                          | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문)                                                                             |
| ------------------------------------------- | ---------------------------------------------------------------------------------- | ------------- | -------------------------------------------------------------------------------------------- |
| 저장 기능이 없어 다시 열면 배치가 사라진다.                   | 영화를 옮기고 새 영화를 추가한 뒤 다시 열었더니 처음 상태로 돌아왔다.                                           | 반영            | 기획서에 같은 브라우저에서 다시 열어도 영화와 등급이 남아야 한다고 적혀 있다.                                                 |
| 처음으로를 눌러도 직접 추가한 영화가 남는다.                   | 듄을 추가하고 처음으로를 눌렀더니 듄은 사라지고 처음 영화 8개만 남았다.                                          | 보류            | 직접 해 보니 아니다. AI가 그럴듯하게 말했지만 현재 초기화 동작은 기획서대로 작동한다.                                           |
| 빈 제목을 추가하면 글자 없는 카드가 생긴다.                   | 입력칸을 비운 채 추가를 누르자 빈 카드가 생겼다. 띄어쓰기만 넣어도 똑같이 빈 카드가 생겼다.                              | 반영            | AI는 기획서를 어긴다고 했지만 민수 님 기획서에는 빈 제목 조건이 없다. 기획서 조건은 아니지만 어떤 영화인지 알 수 없는 카드가 생겨 쓰다가 불편하므로 반영한다. |
| 등급마다 색이 달라서 구분하기 쉽다.                        | S·A·B·C가 서로 다른 색으로 표시돼 한눈에 구분됐다.                                                   | 반영            | 잘된 부분이라 현재 방식을 유지하면 좋겠다.                                                                     |
| 전체 영화 수와 나눈 영화 수가 보여서 좋다.                   | 영화를 옮길 때마다 `8편 중 1편 나눔`처럼 숫자가 바뀌었다.                                                | 반영            | 남은 영화 수를 바로 확인할 수 있어 정리할 때 도움이 된다.                                                           |
| 카드를 끌어 놓을 때 칸 색이 바뀌어 위치를 알기 쉽다.             | 카드를 등급 칸 위로 가져가자 해당 칸의 배경색이 바뀌었다.                                                  | 반영            | 드롭 위치를 알려 주는 표시가 제대로 작동하고 유용했다.                                                              |
| 휴대폰으로 열면 불편하다.                              | 창 너비를 줄이자 오른쪽 내용이 화면 밖으로 잘렸고 옆으로 스크롤도 안 됐다.                                        | 반영            | 기획서의 좁은 화면 완성 기준을 만족하지 못하는 실제 문제다.                                                           |
| 카드 옮기는 방법이 처음에는 헷갈린다.                       | 누르기와 끌어 놓기 모두 잘 옮겨졌고 위에 '영화 카드를 선택한 뒤 등급을 누르세요' 안내도 있었다. 무엇이 헷갈렸는지는 의견만으로 알 수 없었다. | 되묻기           | "카드를 먼저 눌러야 한다는 게 헷갈렸나요, 끌어 놓는 방법이 헷갈렸나요? 어느 장면에서 막혔는지 알려 주실 수 있나요?"                         |
| 미분류 영화가 아래에 있어 S칸까지 드래그하기 불편하다.             | 미분류에서 S칸까지 끌려면 화면을 위로 움직여야 했다. 다만 카드를 선택한 뒤 S 글자를 누르는 방법은 잘 작동했다.                  | 보류            | 이미 클릭으로 옮기는 짧은 방법이 있어 전체 배치를 바꿀 필요는 크지 않다.                |
| 카드 색이 칙칙하다.                                 | 회색 계열이라 차분하게 보이지만 기능 사용에는 문제가 없었다.                                               | 보류            | 색감은 취향 차이가 크고 기획서에서 정한 조건도 아니다.                                                              |
| 영화 포스터가 있으면 좋겠다.                            | 현재는 제목만 표시된다.                                                                      | 보류            | 기획서는 제목 카드 중심이고 외부 파일 없이 HTML 한 장으로 여는 조건이 우선이다. 포스터 자료를 추가하면 범위가 커진다.                       |
| C칸은 없어도 될 것 같다.                             | C등급도 다른 등급과 똑같이 이동하고 분류할 수 있었다.                                                    | 보류            | 기획서에서 S·A·B·C 네 등급을 사용하기로 정했기 때문에 개인 취향만으로 빼기 어렵다.                                           |

- 아무도 말하지 않았는데 내가 찾은 것: 이미 있는 `기생충`을 다시 입력해도 같은 제목의 카드가 하나 더 생겼다. 같은 영화를 여러 장 만들면 어느 카드가 원래 카드인지 헷갈릴 수 있어 중복 제목을 확인하는 처리가 있으면 좋겠다.
