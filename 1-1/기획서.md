# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나
- 나 혼자 쓴다. 개인 기록용이다.
- 주로 PC에서 쓰고, 휴대폰·태블릿처럼 좁은 화면에서도 쓸 수 있다.

## 2. 무엇을 하려고
- 내가 본 영화를 S / A / B / C / D / F 티어로 나눠 정리한다.
- 브라우저를 껐다 켜도 결과가 그대로 남아 있게 한다.
- 다른 컴퓨터에서는 저장 파일을 불러와 이어서 쓴다. 저장 파일이 없으면 처음부터 새로 시작한다.
- 다시 열었을 때 사용자 정보와 티어리스트를 그대로 확인할 수 있다.

## 3. 화면과 동작

### 화면 배치 (위에서 아래로)
1. **상단 바:** 제목, 닉네임(표시·수정), TMDB 설정 버튼, 사용법 버튼, 내보내기 버튼, 불러오기 버튼
2. **검색 영역:** 검색창, 검색 결과(최대 5개, 더 보기 없음), "직접 추가" 버튼
3. **티어 영역:** S / A / B / C / D / F 줄. 각 줄 왼쪽에 티어 이름을 색깔 띠로 표시한다
4. **미분류 대기칸:** 새로 추가한 영화가 들어가는 곳
5. **하단:** TMDB 출처

- 디자인은 깔끔한 밝은 테마로 한다.
- 티어리스트는 하나만 두고, 티어는 S~F로 고정한다.
- 티어 칸과 미분류 칸에는 **포스터만** 보여준다.
- 화면 폭이 좁아지면 상단 바 버튼과 검색 영역은 줄을 바꿔 배치하고, 티어 이름 띠와 포스터 크기를 줄여 오른쪽이 잘리지 않게 한다. 팝업도 화면 안에 들어오게 한다.

### 영화 추가
- **TMDB 검색:** 검색 결과는 최대 5개까지 보여준다. 결과마다 포스터, 제목, 연도, 추가 버튼이 있다.
- **직접 추가(보조):** 제목과 연도를 입력해 추가한다. 이렇게 추가한 영화는 포스터 대신 제목이 적힌 기본 카드로 보인다.
- 추가한 영화는 미분류 칸에 들어간다.
- 같은 영화는 두 번 추가되지 않는다.
  - TMDB 영화는 TMDB id가 같으면 같은 영화로 본다.
  - 직접 추가한 영화는 제목과 연도가 같으면 같은 영화로 본다.

### 티어 옮기기
- 기본은 드래그 앤 드롭이다. 같은 티어 안에서 순서를 바꾸는 것도 드래그로 한다.
- 보조로 상세 팝업의 S~F·미분류 버튼을 쓴다.
- 휴대폰에서는 드래그가 되지 않을 수 있으므로 상세 팝업의 버튼으로 옮긴다.

### 상세 팝업 (포스터 클릭)
- 보여주는 것: 포스터, 제목, 개봉연도
- 입력·수정하는 것:
  - 별점: 0.5~5, 반 점 단위. 0점은 없고, 비워 두면 "평가 안 함"이다.
  - 본 날짜: 달력에서 고른다.
  - 한줄평
- 세 항목 모두 비워 둬도 저장된다.
- 버튼: 티어 변경(S~F·미분류), 삭제, 닫기

### 영화 CRUD
- 미분류 칸과 티어 칸 모두에서 추가·조회·수정·삭제할 수 있다.
- 삭제할 때는 확인 창을 띄운다.

### 사용자 정보
- 닉네임을 저장한다.
- 처음 열었을 때 닉네임을 정하고, 나중에 상단 바에서 바꿀 수 있다.
- 저장 파일을 불러와도 현재 브라우저의 닉네임은 바뀌지 않는다.

### TMDB 인증 설정
- TMDB 인증값이 없으면 처음 실행할 때 별도 설정 창을 보여준다. 나중에 설정할 수도 있다.
- 상단의 **TMDB 설정** 버튼에서 언제든 인증값을 입력·교체·삭제할 수 있다.
- 다음 두 형식을 모두 지원한다.
  - API Key(v3 auth)
  - API Read Access Token(Bearer 토큰)
- 설정 창 안에 회원가입 → 이메일 인증 → 설정의 API 메뉴 → 약관 동의·신청 → 인증값 복사 순서의 발급 설명을 넣는다.
- 입력한 인증값은 영화 데이터와 분리해 현재 브라우저에만 저장한다.
- 저장할 때 TMDB 연결을 확인하고 성공·실패 결과를 안내한다.
- 인증값은 비밀번호처럼 가려서 표시하며, 보기·숨기기와 저장된 값 삭제 기능을 제공한다.
- 인증값은 md 내보내기 파일에 포함하지 않는다.

### 내장 사용설명서
- 상단의 **사용법** 버튼을 누르면 별도 파일 없이 페이지 안에서 전체 설명서를 볼 수 있다.
- 설명서에는 다음 내용을 모두 포함한다.
  - 처음 시작하기와 닉네임 변경
  - TMDB 인증값 발급·입력·삭제 방법
  - 영화 검색·직접 추가와 중복 기준
  - 드래그로 티어 이동·순서 변경, 상세 기록·삭제 방법, 휴대폰에서 상세 팝업 버튼으로 옮기는 방법
  - 자동 저장 범위와 브라우저 데이터 삭제 시 주의사항
  - md 내보내기·불러오기와 덮어쓰기 범위
  - 인증값 보안 주의와 검색 오류 해결 방법

### 저장
- **자동 저장:** 영화를 추가·수정·삭제·이동할 때마다 브라우저에 자동으로 저장한다.
- **내보내기:** 날짜가 붙은 md 파일로 내보낸다. 예: `movie-tierlist-2026-11-05.md`
  - 파일 안에는 사람이 읽기 좋은 목록(티어별 영화, 별점, 본 날짜, 한줄평)과 복원용 데이터를 함께 넣는다.
- **불러오기:** md 파일을 불러오면 현재 영화 목록·티어·별점·본 날짜·한줄평을 덮어쓴다.
  - 현재 브라우저의 닉네임과 TMDB 인증값은 덮어쓰지 않고 그대로 유지한다.
  - 덮어쓰기 전에 "현재 영화 기록이 사라집니다. 닉네임과 TMDB 설정은 유지됩니다" 확인 창을 띄운다.
  - 이 페이지에서 만든 파일이 아니거나 손상된 파일이면 "불러올 수 없는 파일입니다" 안내만 띄우고, 기존 데이터는 그대로 둔다.
- 저장된 데이터가 없으면 빈 상태로 새로 시작한다.

### 인증값 오류 처리
- 인증값이 비어 있으면 설정 창을 열 수 있는 버튼과 함께 검색 영역에 안내를 띄운다.
- 인증값이 잘못되었거나 인터넷 연결 문제로 검색이 실패하면 인증값과 연결 상태를 확인하라는 안내를 띄운다.
- 검색을 사용할 수 없는 동안에도 직접 추가와 기존 영화 기록 편집은 계속 사용할 수 있다.

## 4. 필요한 자료
- **기술:** HTML / CSS / JS만 사용한다.
- **결과물 파일:**
  - `영화_B_초안.html`: 페이지, TMDB 설정 창, 사용설명서를 한 파일에 모두 담는다. 이 파일 하나만 있으면 동작한다.
  - 별도의 `사용설명서.md`는 만들지 않고 HTML 내부 사용설명서로 제공한다.
- **영화 데이터:** TMDB API(한국어 결과)
  - 사용자가 페이지 설정 창에서 v3 API 키 또는 API Read Access Token을 입력한다.
  - 코드의 기본 인증값은 비워 두고, 기획서와 공개 파일에는 실제 인증값을 적지 않는다.
  - 비상업적 무료 이용 조건에 따라 하단에 TMDB 출처를 표시한다.
- **코드 안 주의 문구:** 기본 인증값 줄 옆에 "공개 저장소에 올릴 때는 비우세요" 주석을 단다.
- **저장 파일:** 날짜가 붙은 md 파일

## 5. 완성 기준
- [ ] 처음 열면 닉네임을 정할 수 있고, 상단에 표시되며, 나중에 바꿀 수 있다
- [ ] TMDB 인증값이 없으면 설정 창이 열리고, v3 API 키 또는 API Read Access Token을 입력할 수 있다
- [ ] 저장된 인증값을 교체·삭제할 수 있고, 연결 성공·실패 안내가 표시된다
- [ ] 페이지 안 사용설명서에서 발급·사용·저장·복원·보안 설명을 모두 확인할 수 있다
- [ ] TMDB에서 한글로 검색하면 포스터, 제목, 연도가 최대 5개까지 나온다
- [ ] 제목·연도를 직접 입력해서 추가할 수 있다
- [ ] 추가한 영화가 미분류 칸에 들어간다
- [ ] 같은 영화는 두 번 추가되지 않는다
- [ ] 티어 칸과 미분류 칸에는 포스터만 보인다(직접 추가한 영화는 제목 카드로 보인다)
- [ ] 드래그와 팝업 버튼으로 티어를 옮길 수 있다
- [ ] 화면 폭을 휴대폰 정도로 줄여도 오른쪽이 잘리지 않고, 팝업 버튼으로 영화를 옮길 수 있다
- [ ] 같은 티어 안에서 순서를 바꿀 수 있다
- [ ] 포스터를 클릭하면 팝업에서 별점(0.5~5, 비우기 가능), 본 날짜(달력), 한줄평을 입력·수정할 수 있다
- [ ] 티어에 있는 영화도 추가·조회·수정·삭제할 수 있다
- [ ] 삭제할 때 확인 창이 뜬다
- [ ] 새로고침하거나 브라우저를 껐다 켜도 데이터가 그대로 남아 있다
- [ ] 날짜가 붙은 md 파일로 내보낼 수 있고, 메모장으로 열어도 내용을 읽을 수 있다
- [ ] 다른 브라우저에서 md를 불러오면 영화 기록이 똑같이 복원된다(확인 창을 거친 뒤 덮어쓰기)
- [ ] md를 불러와도 현재 브라우저의 닉네임과 TMDB 인증값은 바뀌지 않는다
- [ ] 잘못된 파일을 불러오면 안내가 뜨고, 기존 데이터는 그대로 남는다
- [ ] 저장 데이터가 없으면 빈 상태로 새로 시작한다
- [ ] 인증값이 없거나 잘못되었으면 검색 영역에 안내와 설정 버튼이 뜬다
- [ ] 화면 하단에 TMDB 출처가 표시된다
- [ ] HTML 내부 사용설명서에 내보내기·불러오기 방법과 인증값 발급 방법이 들어 있다
