TMDB connection

TMDB 인증값 설정

영화 검색에 사용할 v3 API 키 또는 API Read Access Token을 입력하세요.

입력값은 이 브라우저에만 저장되며 영화 MD 파일에는 포함되지 않습니다.

TMDB 인증값 발급 방법

  1. TMDB 회원가입 후 이메일 인증과 로그인을 완료합니다.
  2. 우측 상단 프로필 → 설정(Settings) → 왼쪽 메뉴의 API를 선택합니다.
  3. 약관에 동의하고 용도에 맞는 신청 유형을 선택한 뒤 신청 정보를 작성합니다. 개인 기록용이면 비상업적 용도를 선택합니다.
  4. 발급 화면에서 API Key(v3 auth) 또는 API Read Access Token 중 하나를 복사해 위 입력칸에 붙여넣습니다.
🔒
보안 주의인증값은 비밀번호처럼 다루세요. 이 HTML을 공유하거나 공개 저장소에 올릴 때 코드에 값을 직접 적지 마세요. 공용 PC에서는 사용 후 아래의 ‘저장된 인증값 삭제’를 누르세요.

User guide

사용설명서

이 영화 티어리스트의 모든 기능과 저장 방식을 안내합니다.

이 페이지는 설치 없이 HTML 파일 하나로 실행됩니다. 영화 기록은 현재 브라우저에 자동 저장되며, 다른 컴퓨터로 옮길 때는 MD 파일을 이용합니다.

01처음 시작하기
  1. 처음 열면 닉네임을 입력합니다. 닉네임은 상단 프로필 버튼에서 언제든 바꿀 수 있습니다.
  2. TMDB 검색을 사용하려면 상단의 TMDB 설정에서 인증값을 저장합니다.
  3. 인증값 없이도 직접 추가로 제목과 개봉 연도를 입력해 사용할 수 있습니다.
02TMDB 인증값 발급 및 입력

TMDB 계정 가입 → 이메일 인증 → 프로필의 설정 → API 메뉴 → 약관 동의 및 신청 정보 작성 순서로 발급합니다. 발급 페이지의 API Key(v3 auth) 또는 API Read Access Token 중 하나를 사용할 수 있습니다.

상단의 TMDB 설정을 누르고 값을 붙여넣은 뒤 저장하고 연결 확인을 누르세요. 연결 성공 후 한글 영화 검색과 포스터 불러오기가 활성화됩니다.

TMDB 공식 안내에 따르면 v3 API는 API 키 쿼리 방식과 Bearer 읽기 토큰 방식을 모두 지원합니다. 발급 신청은 PC 브라우저 사용을 권장합니다.

03영화 추가와 중복 기준
  • TMDB 검색: 영화 제목을 입력하면 한국어 검색 결과를 최대 5개 표시합니다. 결과의 + 버튼을 누르면 미분류 칸에 추가됩니다.
  • 직접 추가: 제목과 개봉 연도를 입력합니다. 포스터 대신 제목 카드가 표시됩니다.
  • TMDB 영화는 같은 TMDB ID, 직접 추가 영화는 같은 제목과 연도를 중복으로 판단합니다.
04티어 이동과 영화 기록
  • 포스터를 S/A/B/C/D/F 또는 미분류 칸으로 드래그해 이동합니다. 같은 칸 안에서도 드래그해 순서를 바꿀 수 있습니다.
  • 포스터를 클릭하면 별점(0.5~5점, 0.5 단위), 본 날짜, 한줄평을 기록할 수 있습니다.
  • 상세창의 티어 버튼으로도 이동할 수 있으며, 삭제 시 확인창이 표시됩니다.
  • 휴대폰에서는 드래그가 되지 않을 수 있으니, 포스터를 눌러 상세창의 티어 버튼으로 옮겨 주세요.
  • 별점·본 날짜·한줄평은 모두 비워 둔 상태로도 저장할 수 있습니다.
05자동 저장과 브라우저 데이터

닉네임, 영화 추가·수정·삭제·이동 결과는 작업할 때마다 브라우저의 로컬 저장 공간에 자동 저장됩니다. 새로고침하거나 브라우저를 다시 열어도 같은 브라우저에서는 기록이 유지됩니다.

주의: 브라우저의 사이트 데이터·쿠키·저장 데이터를 삭제하거나 시크릿 모드에서 창을 닫으면 기록이 사라질 수 있습니다. 중요한 기록은 정기적으로 내보내세요.
06MD 내보내기와 불러오기
  • 내보내기: 상단의 내보내기를 누르면 movie-tierlist-YYYY-MM-DD.md 파일이 저장됩니다. 티어별 목록과 복원용 데이터가 함께 들어 있습니다.
  • 불러오기: 다른 컴퓨터나 브라우저에서 이 HTML을 열고 불러오기를 눌러 저장한 MD 파일을 선택합니다.
  • 불러오기는 현재 영화 기록만 완전히 덮어씁니다. 현재 닉네임과 TMDB 인증 설정은 그대로 유지되며, 확인창에서 동의해야 영화 기록이 교체됩니다.
  • 손상되었거나 이 페이지에서 만든 파일이 아니면 기존 데이터를 변경하지 않고 오류만 안내합니다.
  • 보안을 위해 TMDB 인증값은 MD 파일에 포함되지 않습니다. 새 컴퓨터에서는 인증값을 다시 입력해야 합니다.
07보안과 문제 해결
  • 인증값은 브라우저에만 저장하지만, 이 장치를 사용하는 사람은 접근할 수 있습니다. 개인 PC에서 사용하세요.
  • HTML 코드에 인증값을 직접 입력한 상태로 파일을 공유하거나 GitHub 등 공개 저장소에 올리지 마세요.
  • 검색이 실패하면 TMDB 설정에서 인증값을 다시 저장해 연결을 확인하세요. 인터넷 연결과 TMDB 서비스 상태도 확인하세요.
  • 검색을 사용할 수 없어도 직접 추가와 기존 영화 기록 편집은 계속 사용할 수 있습니다.
